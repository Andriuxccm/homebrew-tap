# Argon for Homebrew

[Argon](https://argonmac.com/) turns the MacBook notch into a live island for music, calls, AirPods, timers and files.

```sh
brew install --cask andriuxccm/tap/argon
```

Argon keeps itself up to date. This tap also follows every release on its own, so `brew upgrade --cask --greedy argon` works too.

Already installed Argon from the website? `brew install --cask --adopt andriuxccm/tap/argon` lets Homebrew manage that copy.
